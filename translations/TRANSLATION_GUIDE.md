# 牌效翻譯規範（日文 → 繁體中文，台灣用語）

輸入：`ja_XX.json`，格式 `{卡名: {"B"|"E": [牌效, flavor]}}`（B=基本卡、E=進化卡）。
輸出：同資料夾 `zh_XX.json`，**結構完全相同**（同一批卡名、同一批 B/E 鍵，值為 `[中文牌效, 中文flavor]`；flavor 日文為空字串就輸出空字串）。

## 硬性規則（merge_zh.py 會驗證，不合格整條作廢）
1. 半形方括號的圖示 token 必須**原封不動保留日文**，數量一致：`[進化]`、`[コスト1]`、`[攻撃力]`、`[体力]`、`[クイック]`、`[UB]`、`[Q]`、`[食事]`、`[憑依]`、`[アドバンス起動]` 等。
   例外只有三個關鍵字要轉成全形中文：`[ファンファーレ]`→`【入場曲】`、`[ラストワード]`→`【謝幕曲】`、`[起動]`→`【起動】`。
2. 卡名引用 `『…』` 內的日文卡名**保持日文不翻**（網站用日文卡名對照）。
3. 中文長度不可短於日文的 45%，不可省略任何句子；換行 `\n` 與分隔線 `―――` 原樣保留。
4. 只輸出 JSON，不要加註解或 markdown 圍欄。

【覚醒】→【覺醒】、【潜伏】→【潛伏】、【スタック】→【堆疊】、【コンボ_n】→【連擊_n】、【ネクロチャージ_n】→【死靈充能_n】、【レッスン_n】→【課程_n】、
